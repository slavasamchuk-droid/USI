# Реестр рекламных материалов — ЮгСтройИнвест

Статичный сайт-реестр материалов по ЖК Ростова-на-Дону. Данные берутся **прямо из вашей Google Таблицы** — правки в таблице появляются на сайте после обновления страницы.

Имя проекта из логотипа: **ЮгСтройИнвест → `yugstroyinvest`**.

| Файл | Назначение |
|---|---|
| `index.html` | весь сайт: разметка, стили, логика, логотип |
| `data.csv` | резервная копия данных на случай, если таблица недоступна |
| `README.md` | эта инструкция |

---

## 1. Как реестр берёт данные

При открытии страница пробует источники по очереди и берёт первый рабочий:

1. **Опубликованная таблица** (`PUB_CSV`, если заполнен) — самый стабильный вариант;
2. **Google Таблица напрямую** (`gviz`-выгрузка по ID);
3. **`data.csv`** рядом с сайтом — работает всегда, даже без интернета до Google;
4. **встроенная копия** внутри `index.html` — последний резерв.

Внизу панели видно, какой источник сработал и когда данные загружены. Кнопка **Обновить** перечитывает таблицу без перезагрузки страницы.

### Что нужно сделать один раз

**Открыть доступ к таблице:** «Настройки доступа» → «Доступ по ссылке» → **Читатель**. Без этого браузер посетителя таблицу не прочитает.

**Надёжнее — опубликовать лист:** Файл → «Поделиться» → **Опубликовать в интернете** → лист «Лист1», формат **CSV** → Опубликовать. Полученный адрес вставить в `index.html`:

```js
const CFG = {
  SHEET_ID : "1nOhQsrg-r4tE1VWGQIVfX4YdRHY28L7yKaseoymblag",
  GID      : "0",
  PUB_CSV  : "https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv",
  LOCAL_CSV: "data.csv",
```

Публикация обновляется автоматически, но с задержкой до ~5 минут.

## 2. Как оформлять таблицу

Правила простые, ломать структуру не нужно — она уже подходит.

**Раздел.** Строка, где колонка A заполнена, а B пустая: «Мобильные буклеты:», «Генпланы А3:». Двоеточие необязательно.

**Материалы.** Колонка A — название ЖК, колонка B — ссылки. Несколько ссылок в одной ячейке пишутся с новой строки (Alt+Enter):

```
5 литер https://disk.yandex.ru/i/z1Z8oKtVWZEuAQ
4 литер https://disk.yandex.ru/i/mHGOaSv5O5lOow
```

Текст **до** ссылки становится подписью кнопки. Если подписи нет, берётся название из колонки A.

**Дата обновления.** В любую колонку правее B впишите дату — она попадёт в метку «обновлено» под названием:

```
C: 14.01.2026 10:30     или просто     14.01.2026
```

Если даты нет, реестр попробует взять её из имени файла (`...20.03.26.pdf`). Если и там нет — покажет «дата не указана». Материалы моложе **45 дней** подсвечиваются автоматически.

## 3. PDF и ссылки

В текущей таблице **все материалы вставлены обычными ссылками** — файлов-чипов больше нет, все кнопки рабочие. Если снова появится чип (значок PDF внутри ячейки), реестр покажет кнопку «Нужна ссылка»: из выгрузки таблицы адрес такого вложения не извлекается. Лечится вставкой обычной ссылки текстом в ту же ячейку.

Счётчик «без ссылки: N» в панели показывает, сколько строк осталось без адреса. Сейчас таких две: **78 кластер** в ПДФ-рендерах и **15 литер Сияния** в дизайн-проектах.

Ссылки на Google Диск в России открываются медленно и не всегда. Где возможно, лучше дублировать материалы на Яндекс.Диск — как уже сделано для генпланов, коммерции, фото и видео.

### Кнопка «Шахматка»

В шапке справа стоит кнопка на `https://usi.allio.app:30202/allio/building/buildings`. Адрес меняется в `index.html` — поиск по строке `class="chess"`.

## 4. Размещение: доступ из России без VPN

Важно: **Netlify в России заблокирован**, Vercel и Cloudflare Pages работают через раз. Для российской аудитории нужен российский хостинг.

### Вариант А. Яндекс Object Storage — бесплатно при малом трафике

1. Зайти в **console.yandex.cloud**, создать платёжный аккаунт (нужна карта, списаний при таком объёме практически нет — сайт весит меньше 100 КБ).
2. **Object Storage → Создать бакет.** Имя: `yugstroyinvest-materials`. Максимальный размер 1 ГБ, публичный доступ на **чтение объектов** и **чтение списка объектов**.
3. Загрузить `index.html` и `data.csv`.
4. **Настройки бакета → Веб-сайт** → Главная страница: `index.html` → Сохранить.
5. Сайт доступен по адресу вида `https://yugstroyinvest-materials.website.yandexcloud.net`.
6. Свой домен: в **Cloud DNS** (или у регистратора) создать CNAME `materials.yugstroyinvest.ru` → адрес бакета, бакет **переименовать точно в домен** — это требование Яндекса. Сертификат выпускается бесплатно в **Certificate Manager**.

### Вариант Б. Timeweb / Beget / Sweb — проще, от ~300 ₽/мес

Обычный хостинг: загрузить `index.html` и `data.csv` по FTP в папку `public_html`. Домен и SSL подключаются в панели в два клика. Ничего кроме статики не требуется — ни PHP, ни базы.

### Вариант В. Внутренняя сеть

Если реестр только для сотрудников — положить `index.html` на внутренний сервер или в общую папку. Файл открывается двойным кликом и работает локально: при отсутствии доступа к Google он покажет данные из `data.csv`.

### Что уже сделано для работы без VPN

- Шрифты Google убраны — используются системные, страница не ждёт `fonts.googleapis.com`.
- Никаких внешних библиотек и CDN.
- Если Google не отвечает за 8 секунд, реестр не зависает, а переключается на `data.csv`.

## 5. Обновление резервной копии `data.csv`

Резерв стоит освежать раз в месяц: Файл → **Скачать → CSV** → переименовать в `data.csv` → загрузить на хостинг вместо старого.

Хотите полностью убрать зависимость от Google — настройте автообновление: **Cloud Functions** в Яндекс Облаке по расписанию скачивает CSV из таблицы и кладёт в бакет. Тогда сайт всегда читает свежий `data.csv` с российского адреса.

## 6. Если что-то не так

- **Показано «Таблица недоступна»** — закрыт доступ по ссылке либо Google не отвечает. Проверьте доступ, нажмите «Обновить».
- **Пропали разделы** — в строке-заголовке случайно заполнилась колонка B, строка стала материалом.
- **Кнопка «Нужна ссылка»** — материал вставлен файлом, см. пункт 3.
- **Материал открывается не тот** — проверьте ячейку: в таблице у Эстета подписи 48 и 49 кластеров стоят у файлов с противоположными именами.
